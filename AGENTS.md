# Repository guidance

Before planning or changing dashboard behavior, read [PRODUCT.md](PRODUCT.md),
[DESIGN.md](DESIGN.md), and [IDEAS.md](IDEAS.md).

Maintain `IDEAS.md` when decisions change or features ship. Distinguish Exploring,
Agreed, Later, and Shipped; agreed direction does not mean implemented behavior
or authorization to build unrelated features. Keep `DESIGN.md` describing what
is implemented, updating it when design changes ship.
